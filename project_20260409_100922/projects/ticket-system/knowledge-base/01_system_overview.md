# 12306购票智能客服系统 - 系统概述

## 项目简介
12306购票智能客服系统是一个基于Spring Boot 3.2 + Vue 3.4的全栈应用，实现了铁路票务的完整业务流程，并集成AI智能客服功能。系统采用前后端分离架构，支持用户注册登录、车票查询预订、订单管理、乘客管理，以及基于RAG（检索增强生成）技术的智能对话服务。

## 技术栈
### 后端
- **框架**: Spring Boot 3.2.0 (Java 17)
- **ORM**: MyBatis Plus 3.5.5
- **数据库**: MySQL 8.0+
- **缓存**: 内存缓存（Caffeine）/ Redis（可选）
- **安全**: JWT认证，BCrypt密码加密
- **AI集成**: LangChain4j 0.36.2，支持Ollama本地模型（如llama3.2:3b）和OpenAI API
- **向量数据库**: ChromaDB（本地嵌入式）
- **构建工具**: Maven

### 前端
- **框架**: Vue 3.4.0 + Composition API
- **构建工具**: Vite 5.0.0
- **UI组件库**: Element Plus 2.5.0
- **状态管理**: Pinia 2.1.7
- **路由**: Vue Router 4.2.5
- **HTTP客户端**: Axios

## 核心功能模块
1. **用户认证模块** - 用户注册、登录、JWT令牌管理
2. **车票预订模块** - 车次搜索、余票查询、席别选择、订单创建
3. **订单管理模块** - 订单支付、退票、历史查询、状态跟踪
4. **乘客管理模块** - 常用联系人管理（支持身份证号加密存储）
5. **智能客服模块** - AI对话、RAG知识检索、工具调用（支持购票、查询等操作）

## 特色技术点
### 1. 统一API响应格式
所有接口返回统一结构的JSON响应：
```json
{
  "success": true/false,
  "code": "状态码",
  "message": "描述信息",
  "data": {}
}
```

### 2. 缓存策略
- **车次缓存**: 缓存热门车次信息，减少数据库查询
- **订单缓存**: 用户订单列表缓存，提高查询性能
- **AI模型缓存**: 模型参数缓存，加速AI响应

### 3. 并发控制与库存管理
- **数据库行锁**: 在创建订单时使用`SELECT ... FOR UPDATE`锁定余票记录
- **乐观锁**: 通过版本号控制数据更新
- **防超卖机制**: 事务中检查库存并扣减，确保数据一致性

### 4. 安全机制
- **密码加密**: BCrypt哈希存储用户密码
- **敏感信息加密**: 乘客身份证号使用AES加密存储
- **JWT令牌**: 无状态认证，支持刷新令牌机制
- **输入验证**: 所有用户输入进行有效性校验

### 5. RAG（检索增强生成）架构
- **知识库向量化**: 系统文档和FAQ存入ChromaDB向量数据库
- **语义检索**: 根据用户问题检索相关上下文
- **工具调用**: AI可以调用业务工具执行购票、查询等操作
- **对话记忆**: 使用`MessageWindowChatMemory`保持会话上下文

## 数据库设计概览
系统包含8个核心数据表：
1. **user** - 用户账户信息
2. **passenger** - 乘客（联系人）信息
3. **train** - 车次基本信息
4. **train_seat_inventory** - 车次余票库存
5. **order** - 订单主表
6. **order_item** - 订单明细（每张票）
7. **knowledge_base** - 知识库文档（用于RAG）
8. **chat_history** - 聊天记录

## 服务端口
- **后端API**: `localhost:8080`
- **前端开发服务器**: `localhost:3000`
- **ChromaDB向量库**: 嵌入式，运行在后端进程内
- **Ollama模型服务**: `localhost:11434`（如使用本地模型）

## 部署与运行
### 开发环境
1. 启动MySQL数据库（端口3306）
2. 运行后端Spring Boot应用
3. 启动前端开发服务器
4. （可选）启动Ollama服务用于本地AI模型

### 生产环境
- 支持Docker容器化部署
- 可配置Redis作为分布式缓存
- 支持Nginx反向代理和负载均衡
